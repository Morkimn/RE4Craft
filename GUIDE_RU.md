# RE4Craft 0.3.1 alpha — руководство

RE4Craft соединяет две запущенные игры: Resident Evil 4 (2005, Steam UHD) и Minecraft Java 26.3. Minecraft выполняет свою игровую логику, а мод рисует его предметы, блоки и интерфейс внутри RE4. PEAK запускать не требуется.

Это экспериментальная версия для одиночной игры. Полное прохождение кампании с мостом ещё не проверено. Для сюжетных действий и сложных переходов используйте F10.

## Что требуется

- Windows 10/11, Steam Resident Evil 4 UHD версии 1.1.0. Ремейк 2023 года не поддерживается.
- Собственный аккаунт Minecraft Java, Prism Launcher и Java 25. Prism получает Minecraft и Fabric штатным способом при первом запуске профиля.
- Достаточно памяти для двух игр; профиль Minecraft выделяет до 4 ГБ.
- Установщик проверяет SHA-256 оригинального `Bin32/bio4.exe`: `19AED4AF0AB06A748FF8744D45AC5580FCD6BE6B6B7E944B1AB8822A00C8EE4A`. Другая версия будет отклонена до изменения файлов.

Пакет содержит моды и настройки. Файлы RE4, Minecraft, аккаунты и миры в пакет не входят. Проект не связан с Capcom, Mojang или Microsoft.

## Установка

1. Запустите Prism хотя бы один раз, настройте собственный аккаунт Minecraft и Java 25. Закройте RE4 и Minecraft, затем закройте окно Prism.
2. Распакуйте ZIP и запустите `RE4Craft-Setup.exe`. Запрос Windows на права администратора нужен для записи в папку Steam под Program Files. Установщик не подписан цифровой подписью.
3. Укажите папку RE4, которая содержит `Bin32`. Обычно это `C:\Program Files (x86)\Steam\steamapps\common\Resident Evil 4`.
4. Укажите **папку данных Prism**, содержащую `instances`. У обычной установки это `%APPDATA%\PrismLauncher`; у переносной версии — папка рядом с `prismlauncher.exe`. Если PEAKCraft уже установил переносной Prism, можно использовать `%LOCALAPPDATA%\PeakCraft\Prism`.
5. Нажмите «Установить / обновить». Появится отдельный профиль **RE4Craft**. Профили PEAKCraft и обычная `.minecraft` не изменяются.

Первый запуск Prism загрузит Minecraft 26.3, Fabric Loader 0.19.5 и необходимые библиотеки. Fabric API 0.161.0+26.3 и гостевой мод SkyCraft 0.1.2-re4.1 уже установлены пакетом. Если Prism сообщает о неподходящей Java, выберите Java 25 в настройках профиля.

Если профиль с именем RE4Craft уже существует и не настроен для этого моста, установщик остановится. Переименуйте этот профиль в Prism либо используйте другую папку данных. Не объединяйте профиль с большим сторонним набором модов.

## Как запускать

1. Запустите Resident Evil 4 обычным способом через Steam. Загружайте нужное сохранение или начните новую игру.
2. В Prism запустите профиль **RE4Craft**. Для установки в `%LOCALAPPDATA%\PeakCraft\Prism` команда запуска профиля — `prismlauncher.exe --launch RE4Craft`.
3. Дождитесь загрузки мира Minecraft и вернитесь в окно RE4. После появления управляемого персонажа мост подключится автоматически. Окно Minecraft может скрываться, но процесс должен оставаться запущенным.

Порядок запуска двух игр не принципиален. Управлять нужно окном RE4. Не запускайте несколько экземпляров моста одновременно. Для обычной кампании уберите из параметров Steam диагностические `-room`, `-pos` и `-angle`, если добавляли их самостоятельно.

## Управление

| Клавиша | Действие |
|---|---|
| **F10** | Переключить Minecraft и обычное прохождение RE4 |
| WASD, мышь | Движение и взгляд Minecraft |
| Space | Прыжок; двойное нажатие в Creative — полёт |
| Shift / Ctrl | Присесть / бежать |
| ЛКМ | Удар мечом, атака, разрушение выбранного блока |
| ПКМ | Использовать предмет, поставить блок; удержать и отпустить для выстрела из лука |
| E | Настоящий инвентарь Minecraft |
| 1–9, колесо | Выбор слота хотбара |
| F5 | Первое лицо и два вида от третьего лица |
| G | Штатное взаимодействие RE4, когда оно доступно |
| O | Меню настроек Minecraft |
| Esc | Закрыть открытый интерфейс Minecraft; без него — штатное меню RE4 |
| T | Чат и команды Minecraft |

Управление Minecraft можно менять в его настройках. F10 зарезервирована мостом. В режиме RE4 возвращаются штатные камера, управление и коллизии Леона; Minecraft HUD, постройки и дополнительные источники света скрываются. Сами постройки остаются в мире. Повторное F10 возвращает Minecraft к текущему положению Леона.

В катсценах, видеороликах и сценах смерти HUD Minecraft скрывается автоматически. После возвращения к игре мост подключается снова. Если сюжетное действие не выполняется через G, нажмите F10 и выполните его штатными клавишами RE4.

## Мир, режимы и сохранения

Новый мир SkyCraft создаётся в Creative со стартовым набором. Для выживания откройте чат и введите `/gamemode survival`; обратно — `/gamemode creative`. Изменения Minecraft сохраняются его обычной системой сохранений. Перед обновлением или удалением мода выйдите из мира через «Save and Quit to Title» и закройте Minecraft.

Minecraft не заменяет сохранения сюжета RE4. Сохраняйте кампанию штатно на пишущей машинке. Копия собственного мира перед большим обновлением рекомендуется; установщик сохраняет прежние файлы мода, а не делает периодическую копию мира.

## Обновление и удаление

Для обновления закройте обе игры и запустите новый `RE4Craft-Setup.exe`, указав те же папки. Первая резервная копия остаётся исходной даже после нескольких обновлений.

Для удаления откройте установщик, укажите прежнюю папку RE4 и нажмите «Удалить мод». Если до установки был другой `dinput8.dll`, он будет восстановлен. Если его не было, DLL моста будет удалена. Установщик восстанавливает только свои перечисленные файлы; оригинальный `bio4.exe` и сохранения кампании не изменяются.

Новый профиль, созданный установщиком, перемещается в `instances/.RE4Craft-removed-ДАТА-ИДЕНТИФИКАТОР`. Его миры остаются внутри `.minecraft/saves`. Если использовался уже существующий совместимый профиль, он остаётся на месте. Скопируйте сохранённый мир в новый совместимый профиль, если решите вернуться к моду.

Манифест и первая резервная копия находятся в `%LOCALAPPDATA%\RE4Craft\backups`. Не удаляйте их до удаления мода. Установщик, который впервые устанавливается поверх вручную установленной версии, считает её предыдущим модом и восстановит её при удалении. Для переноса такой установки предусмотрен параметр `--legacy-backup` с исходной копией файлов; это требует проверки её происхождения.

## Если что-то не работает

- **Нет хотбара:** проверьте, что запущен профиль RE4Craft, загрузился мир и закончилась катсцена. Нажмите F10 один раз и дождитесь подключения.
- **Minecraft закрылся:** RE4 возвращает своё управление. Перезапустите профиль; мост переподключится.
- **Установщик просит закрыть игру:** выйдите из обеих игр, подождите несколько секунд и повторите. Не обновляйте используемую DLL.
- **Не подходит EXE:** используйте поддержанную Steam UHD 1.1.0. Не подменяйте проверку хеша ради другой версии: адреса движка отличаются.
- **Prism не запускает профиль:** проверьте Java 25, аккаунт и журнал Prism. Minecraft и библиотеки должны загрузиться через лаунчер.
- **Зависло сюжетное действие:** F10, выполните его в RE4, затем снова F10.

Журнал моста — `Bin32/dinput8.log`. Журнал Minecraft — `instances/RE4Craft/.minecraft/logs/latest.log`. Перед публичной отправкой журналов удаляйте личные пути, имена и данные аккаунта.

## Проверка и ограничения этой версии

В игре проверены соединение двух процессов, первое лицо, инвентарь, цветная броня, размещение и закрытие блоков геометрией RE4. В тестах проверены проекция, отсечение треугольников, столкновения NPC с блоками и непрерывная поверхность пола на границе регионов.

Исправление пола охватывает физические предметы и опору дверей; для разных комнат, склонов и видов предметов всё ещё нужна игровая проверка. Кеш передачи пола уменьшает повторную работу после изменений, но падение FPS при крупных взрывах может сохраняться. Факелы создают штатные точечные источники света RE4; эффект зависит от материалов сцены. Проецируемые тени блоков упрощены.

Полная кампания, все катсцены, все типы противников, сложные формы коллизий блоков и полная замена взаимодействий мира ещё не проверены. Мост не является законченным переносом всего Minecraft в RE4. Используйте F10 для обычного прохождения.
