# Installer audio

`theme.mp3` is the user-supplied RIVER SOLO track embedded in the installer.
SHA-256: `269addd839cfccd0a973ce4cdc355ef8466075a8d720705a2bcc3097b96b603b`.

The installer plays it at 35% volume and provides an on/off button. Playback
uses Windows MCI, stops when the window closes, and does not run in CLI mode.
The MIT software license does not grant rights to this audio track.
